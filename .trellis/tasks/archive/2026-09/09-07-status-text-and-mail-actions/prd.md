# 配置状态栏用量文案与即时操作

## Goal

让用户无需打开浮窗即可从状态栏查看指定时间范围的 token 与成本摘要，并可从状态栏右键菜单分别主动推送本地用量或拉取远端统计。

## Background and Confirmed Facts

- 当前 `NSStatusItemCoordinator` 使用固定方形长度，只为 `NSStatusBarButton` 配置图标；右键菜单已集中展示快照时间、刷新诊断、设置与退出。
- `ProfilePeriod` 与完整缓存批次已提供“全部、日、周、月”四种范围；每个 `DashboardData` 提供 `totalTokens` 与 `totalCost`。
- `DisplayFormatters` 已提供紧凑 token 数字与 USD 成本格式。
- 当前 `refresh()` 会先执行 CLI submit 再强制拉取全部统计，`retryStatistics()` 只拉取统计，`runAutosubmitNow()` 按自动提交配置运行。
- 用户设置通过 `UserPreferences` / `UserDefaultsPreferencesStore` 持久化。
- 既有契约要求四范围整批发布、静默刷新只拉取线上统计、刷新失败保留旧缓存，并保持 macOS 13 与现有左右键交互。

## Requirements

- R1：常规设置新增“状态栏文案”开关，默认关闭；关闭时状态栏只显示现有图标，打开时在图标右侧显示文案，并让文字基线相对图标轻微下移以改善视觉对齐。
- R2：设置支持编辑状态栏文案模板；默认模板为 `{token} · {cost}`。
- R3：首版仅识别 `{token}` 与 `{cost}`；token 使用既有紧凑格式，状态栏成本使用固定 `$` 前缀的 USD 格式（不改变 Dashboard 的既有货币展示）；其他 `{...}` 内容不校验、不替换，按输入原样展示。
- R4：设置以 Picker/下拉控件配置文案统计时间粒度，可选“全部、日、周、月”，默认“日”。
- R5：开关、模板与时间粒度随现有“保存”操作持久化；旧版本没有对应键或保存了无效范围值时使用默认值。
- R6：状态栏图标右键菜单新增“立刻推送”与“立刻拉取”。推送只执行本地用量 submit，不自动拉取；拉取只强制读取全部远端统计，不执行 submit。
- R7：即时操作安静执行：任一显式操作运行期间两项菜单操作均不可重复触发；成功不额外提示，失败进入既有“刷新详情”诊断入口。
- R8：状态栏文案从对应范围的现有完整缓存派生，并随缓存发布或已保存设置变更更新，不建立独立网络请求。所选范围从未有有效缓存时只显示图标；刷新中或刷新失败且有旧缓存时继续显示旧值。
- R9：保持四范围整批一致性、静默刷新、自动提交、浮窗尺寸、设置窗口及状态栏左右键交互契约。

## Acceptance Criteria

- [x] AC1（R1、R2）：新安装或旧版本升级后开关默认关闭；打开并保存后，有有效“日”数据时显示默认 `{token} · {cost}` 渲染结果，关闭后恢复仅图标。
- [x] AC2（R2、R3）：用户可保存任意模板；只替换所有 `{token}` 与 `{cost}`，其中成本始终显示 `$` 而非 `US$`；未知 `{...}` 保留原文，不增加模板校验界面。
- [x] AC3（R4、R5）：下拉项为“全部、日、周、月”，默认“日”；三项配置重启后保持，缺失键或无效范围安全回退默认值。
- [x] AC4（R8）：切换并保存时间粒度后使用对应完整缓存；无对应有效缓存时只显示图标，刷新中或失败时不清除已有值，展示本身不发起请求。
- [x] AC5（R6）：右键菜单的“立刻推送”恰好执行一次 submit 且不拉取；“立刻拉取”恰好执行一次强制完整批次读取且不 submit。
- [x] AC6（R7）：任何显式操作运行时两个即时菜单项均禁用；即时操作成功保持安静，失败可在下一次打开右键菜单时从“刷新详情”查看。
- [x] AC7（R8、R9）：缓存整批更新和设置保存后状态栏文案及时更新；左键浮窗、右键原生菜单、自动提交及既有静默刷新行为不回归。
- [x] AC8：145 个单元测试通过；2 个状态栏 UI 用例因 SystemUIServer 不暴露状态项而明确跳过；Release 构建、Analyze 与 `git diff --check` 通过。

## Out of Scope

- `{token}`、`{cost}` 之外的变量替换，以及模板校验、条件语句、转义语法或用户自定义数字格式。
- “全部、日、周、月”之外的统计范围，或为状态栏单独请求数据。
- 改变远端 API、Tokscale CLI 命令、自动提交调度策略，或为成功结果增加系统通知/持久提示。

## Risks and Deferred Items

- 用户可输入空模板或超长模板；首版按原文接受，空结果等同仅图标，长度由原生状态栏布局处理，不增加复杂校验或截断设置。
- SystemUIServer 在当前 UI 测试环境不暴露状态项；纯渲染、菜单描述、持久化和 view-model 语义已有确定性单元测试覆盖，真实状态栏标题尺寸与交互仍建议在本地应用中手动确认。
