# 优化首次使用引导

## Goal

把浮窗中当前仅以错误态呈现的首次配置，改造成两步、可直接完成操作的轻量引导，让新用户在不离开浮窗的情况下配置 Tokscale 用户名，并在账号暂无用量时完成第一次提交，最终进入正常仪表盘。

## Background

- 当前浮窗由 `DashboardView` 展示；当用户名为空时，`DashboardViewModel.reloadProfiles` 将统计状态置为失败，并由 `ErrorStateView` 显示“资料暂不可用”和“处理”按钮。
- 当前“处理”按钮只调用 `retryStatistics()`，不会配置用户名或打开可处理问题的界面，因此用户名为空时重试仍然失败，用户感知为按钮无效果。
- 用户名目前只能在设置窗口的“常规”页配置；偏好更新由 `DashboardViewModel.updatePreferences(_:)` 即时持久化。
- 首次打开且没有保存用户名时，现有流程会尝试通过 Tokscale CLI `whoami` 自动发现当前登录账号。
- 已有能力可复用：保存用户名、强制拉取完整统计批次、通过 CLI 提交本地用量并再次拉取统计。

## Requirements

| ID | Requirement |
| --- | --- |
| R1 | 浮窗依据当前账号状态展示首次引导，不新增永久或按用户名保存的“已完成”标记：用户名为空进入第一步；当前用户名无用量进入第二步；累计已有用量则展示正常仪表盘。 |
| R2 | 第一步允许直接输入并保存 Tokscale 用户名；空白输入不能继续。 |
| R3 | 第一步提供轻量的“没有账号”说明和按钮，按钮直接打开 `https://tokscale.ai`；本任务不新增 CLI 登录或应用内注册能力。 |
| R4 | 保留现有 `whoami` 自动识别：本机已登录时自动保存识别到的用户名并继续拉取；识别失败时回到可手填用户名的第一步，不形成无效重试死路。 |
| R5 | 保存有效的非空用户名后立即发起一次强制完整统计拉取，并提供明确的进行中与失败反馈，避免重复触发。 |
| R6 | “已有数据”以全部范围统计的 `totalTokens > 0` 判定；客户端明细是否为空不参与判定。已有数据时结束引导并进入正常仪表盘。 |
| R7 | 拉取成功但全部范围累计 Tokens 为 0 时进入第二步“完成第一次提交”。首次无资料的 `profileNotFound` 可进入第二步，但其他网络、服务端、解码或范围错误必须作为可重试错误展示。 |
| R8 | 第二步提供执行首次提交的主操作，以及修改用户名的恢复入口。提交成功后再次强制拉取；有数据时进入正常仪表盘。 |
| R9 | 第二步提交失败时允许重试；提交后仍为零 Tokens 或仍未找到对应资料时留在第二步，并明确提示检查用户名或稍后重试，不伪报完成。 |
| R10 | 修复当前首次使用场景下“处理”按钮无有效处理路径的问题；非首次使用的普通统计加载错误仍使用统计重试，不改变其语义。 |
| R11 | 引导在现有 380×680 浮窗内完成，使用原生 macOS SwiftUI 控件，不改变 NSPopover 根背景、设置页、状态栏菜单和自动提交的既有业务语义。 |

## Acceptance Criteria

- [x] AC1（R1、R2、R3）：无保存用户名且自动识别未成功时，浮窗展示第一步、用户名输入框、继续主按钮，以及可打开 Tokscale 官网的“没有账号”入口；空白输入不能继续。
- [x] AC2（R4）：本机已有 Tokscale 登录时，首次打开可通过 `whoami` 自动保存用户名并继续验证；自动识别失败后仍能手动输入，不显示只会重复失败的“处理”路径。
- [x] AC3（R5）：提交合法用户名后偏好被持久化，并立即触发一次强制完整拉取；期间显示加载状态且不能重复触发。
- [x] AC4（R6）：完整拉取返回全部范围 `totalTokens > 0` 时，引导结束并展示正常仪表盘数据，即使客户端明细为空也不阻塞完成。
- [x] AC5（R7）：完整拉取成功但全部范围累计 Tokens 为 0，或首次资料不存在时，界面切换到第二步“完成第一次提交”；其他读取错误显示在当前步骤并可重试。
- [x] AC6（R8）：第二步执行提交后会再次强制拉取；返回累计 Tokens 大于 0 时引导结束并展示正常仪表盘；用户可返回修改用户名。
- [x] AC7（R9）：CLI 提交失败可重试；提交后仍为零 Tokens 或资料不存在时不退出引导，并提供检查用户名或稍后重试的明确反馈。
- [x] AC8（R10）：非首次使用的普通统计错误态仍执行统计重试，不再以含糊且无法解决问题的按钮文案处理空用户名。
- [x] AC9（R11）：引导在固定浮窗中可完整显示，支持浅色/深色、键盘操作及必要的 accessibility identifier/label，不新增根级不透明背景或第二材质层。
- [x] AC10：现有设置页用户名编辑、正常仪表盘刷新、状态栏右键推送/拉取、缓存隔离和自动提交行为不回归。
- [x] AC11：新增的引导状态、自动发现、用户名验证、零数据、资料不存在、提交成功/失败及提交后仍无数据至少由 ViewModel 单元测试覆盖，并通过项目既有测试与 Release 构建检查。

## Out of Scope

- 在应用内创建 Tokscale 账号、执行 `tokscale login` 或嵌入完整注册网页。
- 改造 Tokscale 服务端 API、CLI 提交协议或账号体系。
- 扩展为多页教程、功能巡览、动画演示或全屏欢迎页。
- 保存独立的设备级或用户名级引导完成状态。
- 在本任务中重做设置窗口、自动提交配置或普通仪表盘视觉结构。

## Product Decisions

- 引导完成状态完全由当前用户名与线上累计 Tokens 推导。
- “没有账号”只打开 Tokscale 官网。
- 已有数据的唯一判定是全部范围 `totalTokens > 0`。
- 保留 `whoami` 自动识别，并在识别成功时自动跳过手填步骤。
