# 技术设计

状态：用户已确认首版包含编辑已有条目，等待最终规划评审。一个任务覆盖该跨层闭环，不拆成独立交付的父子任务。

## 边界

- CustomPricingFileStore：读取原始 JSON、校验结构、保留未知字段、增删改、原子保存及外部变更检查。文件是唯一事实来源，UserDefaults 不复制价格。
- CustomPricingViewModel：MainActor ObservableObject；持有列表、选中、表单、文件操作和检测状态。视图不直接解析文件或 CLI 文本。
- TokscaleCLIClient：新增列表查询与 dry-run 调用；复用既有参数数组、npx 定位与 300 秒默认超时。诊断解析为独立纯函数，以完整 ProcessOutput 为输入。
- CustomPricingSettingsView：原生 Table、局部操作区、检测结果与共用的添加/编辑 sheet。SettingsView 仅承接第四个 Tab（位于自动提交与关于之间）。

## 文件读取与保存

1. 用已保存 npx/版本调用 pricing list-overrides --json，获取 CLI 实际解析路径与有效条目投影；按相同环境和工作目录解析相对路径。
2. 读取原始文件及内容快照，构建展示行。不能因 CLI 跳过错误条目就从 UI 和文件中悄悄删除它们；对损坏文档阻止写操作并解释问题。
3. 表单显示四类基础费率，单位 USD / 1M Tokens，nil 与 0 分开。至少一个输入/输出值；其他字段留空不写。兼容已有每 Token 字段，按上游规则解释；不改写无关字段。存在冲突别名或大小写重复键时必须明确处理，禁止静默覆盖。
4. 保存前重新读取并比较文件内容；变化时停止并提示刷新。只更新目标键，原子写入并重新载入。JSON 格式缩进可以标准化，但其他条目数值与元数据语义不丢失。
5. 新建文件时创建最小合法 models 根节点；检测创建竞争。无法写入时保留当前 UI 草稿和原文件。
6. 编辑根据原始键定位条目，表单预填四类基础费率、来源和备注，取消无写入。未修改字段保持原表示；修改费率时仅规范化该字段的每 Token/每百万别名，清空时同时移除对应基础价别名，防止旧值重新生效。保留所有阶梯字段及无关字段，写入后重新读取确认显示值。

## 检测合同

参数后缀固定为 submit、--dry-run；不增加真实 submit，不使用 autosubmit run。使用已保存设置，不保存其他 Tab 草稿。首版以 CLI 默认提交范围检测，页面注明范围及实际报告日期。

输出分为报告、缺价项、非价格警告和原始详情。缺价项包含 provider/model 原始标识、可确定的 model ID、原因、受影响消息数和 Tokens。支持 4.15.0 已验证格式，并为 main 新格式保留适配 fixture；不能把成本为零本身当成缺价。

先剥离 ANSI 控制码，再解析 stdout/stderr；识别全部缺价导致汇总为零的情形。未登录、非零退出、超时、格式不支持、无数据、部分数据源失败、检测结束且未发现缺价分别处理。未知格式保留详情，不能显示通过。对上游版本能力缺失展示版本与升级提示，不静默更改用户配置。

## 状态与闭环

列表载入、文件保存、检测拥有明确状态。检测开始时捕获 CLI 上下文与文件内容版本；用户切换配置或文件发生变化后，迟到的报告只能丢弃或标为过期。检测期间禁用本页写操作及重复检测，其他 Tab 变化用 generation 防止旧结果覆盖。

补价按钮预填确定的模型 ID，不预填推测费率。保存后清晰标示需要重新检查，提供同页再次检测按钮。不存在覆盖时打开添加表单；已有精确覆盖时打开对应条目的编辑 sheet，匹配遵循上游大小写规则。归一化匹配存在歧义时要求用户选择对应条目，不自动改写可能影响其他模型的覆盖。编辑成功更新原行，不重复插入同名键。

## UI

使用系统 Table，列为模型、输入、输出、缓存读、缓存写；来源、备注在选中详情区。底部原生添加/编辑/删除/重新载入按钮；没有选中项时禁用编辑与删除。检测区含“检查缺失价格”、ProgressView、状态与结果 List/Table。长文本可选中复制，按钮有辅助功能标签，Enter/Escape 对应表单保存/取消。

使用能容纳表格的较宽设置窗口并允许合理伸缩，避免在 560pt 宽度挤压五列；最终尺寸通过原生渲染确定。其他 Tab 保留原保存行为和状态，新页独立保存且不关闭窗口。无需 AppKit 手绘或 Figma 设计稿。

## 兼容与回退

只变更 custom-pricing.json；不触碰凭据、Tokscale settings.json、LaunchAgent。读取路径/价格与 dry-run 使用同一 CLI 上下文。撤销产品代码不恢复或清空用户已经保存的价格。CLI 不支持诊断时保留可查看的文件内容与明确错误，不猜测成功。
