# 自定义价格设置与缺价检测闭环

## 状态

2026-09-04，可行性调研完成，用户已确认首版支持编辑已有条目。需求已收敛，PRD、技术设计、执行计划及上下文文件已准备好，等待最终规划评审。任务保持 planning，尚未开始产品实现。

## 目标

用户在设置页查看和管理 Tokscale 的 custom-pricing.json，完成发现缺价、填写价格、保存、重新检测的闭环，无需来回切换终端和文本编辑器。遵循 macOS 设计语言，优先系统控件。

## 背景与已确认事实

- 当前设置页已有常规、自动提交、关于三个原生 Tab；窗口固定 560×600。证据：TokChan/Features/Settings/SettingsView.swift:8、:53、:78。
- 现有通用保存会应用自动提交配置并关闭窗口，不适合价格检测闭环。证据：TokChan/Features/Settings/SettingsView.swift:93；TokChan/Features/Dashboard/DashboardViewModel.swift:172。
- 本机 CLI 为 4.15.0，能读取 14 条有效价格覆盖；已有条目包含来源、备注及四类基础单价。本次真实 dry-run 成功，未报告缺价；这仅代表本次默认提交范围的扫描结果。
- 上游 CLI 提供覆盖列表查询和 submit dry-run，但没有价格增删命令，也没有 submit 专用 JSON 输出。完整证据及版本差异见 research/feasibility.md。

## 需求

| ID | 用户可观察的行为 |
| --- | --- |
| R1 | 设置新增“自定义价格”Tab；保持原生窗口、工具栏导航、键盘操作、系统字体、颜色和明暗外观。 |
| R2 | 展示实际价格文件的当前条目及模型 ID、输入、输出、缓存读取、缓存写入价格；明确美元／百万 Tokens 单位，未填写与零价格可区分。文件未创建时显示可添加的空态。 |
| R3 | 支持添加、编辑和删除。添加与编辑共用表单，可修改四类基础费率、来源和备注；编辑时预填原值，取消不改变文件。校验模型 ID、大小写重复、数值合法性，至少填写输入或输出之一；不推测、不自动补齐价格。 |
| R4 | 提供“检查缺失价格”按钮，调用用户已保存的 Tokscale 版本和 npx 配置，以默认 submit 范围执行 dry-run；显示模型、提供方、受影响消息数、Tokens 和缺价原因。 |
| R5 | 缺价项可发起补价：尚无覆盖时预填模型 ID 进入添加，已有对应覆盖时进入编辑该条目，不重复创建。保存后可再次检查。文件修改后旧报告标为待重新检查，不能将本地保存成功等同于缺价已解决。 |
| R6 | 文件损坏、写入失败、外部修改、CLI 失败、未登录、超时、无法识别输出、数据源退化均有准确反馈；不能把解析失败或无可提交数据显示为“全部价格正常”。 |
| R7 | 保留未主动修改的来源、备注、阶梯价格、兼容字段及未识别字段。编辑只改变用户选定的字段及保证其生效所需的对应单位别名；删除仅移除选定条目，添加不改写其他条目的内容。 |
| R8 | 价格操作不触发真实提交、不应用自动提交设置、不关闭设置窗口；其他 Tab 的草稿不丢失。 |

## 建议交互（待最终评审）

- 价格页独立即时保存：添加或编辑表单确认后落盘，删除通过系统确认后落盘；不沿用全局设置保存。
- 基础价格列表配合条目详情，避免把来源、备注、阶梯价格都塞进横向列；长模型 ID 可复制和查看完整值。
- 检测使用默认 submit 范围，不隐式套用自动提交 Tab 的草稿筛选；页面明确检测范围。
- 不新增实际提交入口，验证完成后沿用现有提交能力。

## 验收标准

- AC1（R1、R2）：新增 Tab 与现有三个 Tab 一同正常切换；原生表格展示当前文件，长模型名、14 条以上记录和空态可用，macOS 13 可编译。
- AC2（R3、R7）：添加后 CLI 能识别新增条目；编辑后 CLI 读取更新后的费率，取消编辑文件不变；删除后目标条目消失，无关字段和其他条目保留；负数、非法数字、重复 ID 被阻止，空值不转换为 0。
- AC3（R4、R5）：缺价报告按是否存在对应覆盖进入添加或编辑表单；覆盖已有条目缺少缓存单价的修复，补价保存后重新 dry-run，实际解决的条目从新报告消失，且没有生成重复覆盖；检测与保存均无真实提交。
- AC4（R6）：全部用量缺价但可提交汇总为零时仍展示缺价项；无数据、检测失败、未知格式与未发现缺价状态区分。
- AC5（R6、R7）：文件被外部修改时不覆盖新内容；文件损坏时不当作空列表重建；失败后原文件仍可读取。
- AC6（R8）：价格页保存不执行 autosubmit enable/disable，未保存的其他配置不生效，窗口保持打开。

## 不在本次范围

自动获取或推荐费率、自动提交用量、全新定价引擎、改写 Tokscale 上游、修改凭据或调度器、通用 JSON 文本编辑器、多配置目录切换、完整阶梯价格编辑器。
