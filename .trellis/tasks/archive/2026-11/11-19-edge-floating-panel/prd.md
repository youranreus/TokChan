# 增加可拖拽贴边的常驻浮窗

## 目标与范围

用户可以选择从菜单栏或屏幕边缘查看同一个完整统计面板。在贴边模式下，用户可将其放到顺手的位置，按需临时查看或固定展开。本次改动限于面板的展示、定位和交互，统计计算与数据同步沿用现有行为。

## 交互与验收

- [x] 在设置的「展示方式」中，以两个互斥按钮呈现「菜单栏浮窗」和「贴边浮窗」。任一时刻恰有一项选中。切换后立即生效，重启恢复所选方式。兼容默认值采用菜单栏浮窗。
- [x] 菜单栏模式下，左键图标在图标下方打开或关闭面板，屏幕边缘没有浮窗。贴边模式下，左键同一图标在当前吸附位置展开面板；已展开时保持可见。
- [x] 两种模式使用当前菜单栏左键打开的完整 DashboardView。在相同数据状态下，可见内容和操作一致，包括切换时间范围、查看客户端和模型明细。
- [x] 切入贴边模式时，屏幕边缘默认只露出完整面板自身的一条可悬停窄边，长度与面板该边一致。面板采用与菜单栏浮层一致的系统磨砂材质。指针移入窄边时，浮窗从该边滑出。指针进入内容区后仍可操作；未固定时，指针移出后浮窗滑回原位。
- [x] 点击大头针固定展开，移开指针仍可持续查看。再次点击解除固定，恢复移出收起。
- [x] 拖动可以在左右两侧之间换边，也能沿当前侧边上下调整位置。拖到顶部或底部时，按松手所在的屏幕半区选择左右侧。展开后与吸附侧留出 8 点间距，收起时仍贴紧侧边。沿边保留鼠标按下时的抓取位置，仅在面板将超出可用屏幕时限位。再次展开和收起均以该处为基准。
- [x] 在面板展开、固定或动画进行中切换展示方式时，旧模式的窗口和窄边退出，后续点击仅唤起新模式。两种模式下均可用菜单栏右键访问原有菜单。
- [x] macOS 26 及以上的贴边模式提供「液态玻璃」开关。默认使用磨砂材质，开启时即时切换整个贴边面板；关闭时恢复磨砂。重启保留选择，切换材质保留面板位置、内容及固定状态。
- [x] 展示配置可调节贴边面板收起时露出的宽度（1–64 pt，默认 7 pt）。已收起的面板即时响应修改，重启后保留选择。拖动后第一次收起沿落点所在侧边滑动，高度和沿边位置保持稳定。
