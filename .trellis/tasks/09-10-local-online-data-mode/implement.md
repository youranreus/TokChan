1. 加载 trellis-before-dev 和相关 macOS specs，核对数据持久化、Tokscale、状态管理及测试合同。
2. 按 research 已核对的 graph stdout 和 config timezone 合同实现能力验证；补充空数据、缺价及不兼容输出的脱敏 fixture。

5. 接入统一刷新协调流程，保留五分钟调度和原有新鲜度/退避/唤醒行为；分离显式在线操作和当前模式面板操作。
6. 增加欢迎页模式选择和独立初始化标记，完成新安装、老用户及在线流程衔接；实现配置清空协调入口与持久化删除，防止在途请求复活旧状态。
7. 适配菜单栏摘要、面板在线指标、账号/空态文案；增加菜单和设置切换控件、软件版本及检查更新行。
8. 更新对应文档和发布说明片段，不实际发布或修改版本号。
9. 按 trellis-check 执行适用验证并报告结果。

## 必须覆盖的行为验证
- 本地导出聚合的总量、成本、五类构成、模型归属、日期边界及空数据；解析失败与真实零数据分离。
- 默认本地、偏好恢复、旧线上快照迁移、不串源；模式切换、账号切换及迟到请求竞态。
- 两来源共用自动刷新/退避/唤醒策略，面板关闭仍刷新；本地面板刷新无 submit/公开资料 API 调用。
- 本地模式显式在线操作只更新线上缓存，不替换面板、菜单栏摘要或选中模式。
- 在线面板既有提交再拉取语义、账号引导、自动提交功能回归。
- 设置和右键切换一致，名称/版本来自 Bundle，检查更新复用可用状态。

主要验证命令：`xcodebuild test -project TokChan.xcodeproj -scheme TokChan -destination 'platform=macOS'`。本机已确认 Xcode 26.6 可用。测试使用假 API/CLI 与临时存储，不能对真实用户执行配置重置；视觉检查欢迎页、本地/在线面板、设置及右键菜单。未修改发布脚本时不扩展到签名/发布测试。

- 欢迎页模式分流、独立初始化标记与旧用户升级；本地无账号和读取失败仍可进入面板。
- 清空覆盖磁盘、内存、初始化与旧快照回退；在途刷新迟到、清理失败及重试；只处理约定所有权范围。
