# 新增客户端列表展示过滤配置

## Goal

让用户在设置中控制面板“客户端用量”列表的展示内容，减少零开销模型和不关注客户端带来的信息干扰。

## Background

- 当前面板直接展示 `DashboardData.clients` 中的全部客户端，并在每个客户端下展示其模型明细。
- 当前常规设置已通过 `UserPreferences` 与 `UserDefaultsPreferencesStore` 持久化界面偏好，并在控件修改时立即保存。
- 本地快照同时持有全部、今天、本周、本月四个统计周期，可用于构建客户端候选项。

## Requirements

- R1：设置窗口新增独立的“展示配置”原生偏好页签。
- R2：展示配置中新增“隐藏开销为 0 的模型”开关，默认关闭。
- R3：R2 开启时，面板客户端卡片内不展示开销恰好为 0 的模型；关闭时恢复现有完整模型列表。该过滤不隐藏客户端卡片本身。
- R4：展示配置中新增“隐藏指定客户端”总开关，默认关闭。
- R5：用户可从多选列表中选择要隐藏的客户端；总开关关闭时收起候选列表、保留选择且不执行客户端过滤。
- R6：客户端候选项由本地四个统计周期已加载数据中的客户端 ID 并集构成，并包含已选但当前各周期均无数据的客户端。候选项按稳定顺序展示。
- R7：客户端过滤启用后，已选客户端不在面板列表中展示；未选客户端保持现有顺序。
- R8：两类展示配置修改后立即生效并持久化，应用重启后继续生效。
- R9：过滤仅改变面板客户端及模型明细的可见性，不改变顶部汇总指标、状态栏摘要、服务端数据或本地原始快照。
- R10：旧版本未保存过新配置时，两个过滤开关均默认关闭，隐藏客户端集合为空，保持现有展示行为。
- R11：客户端多选项采用每个客户端独立的原生 switch，并显示对应客户端图标；顶部总开关继续控制过滤是否生效。
- R12：面板与展示配置列表使用统一的 macOS 应用图标风格（圆角与轻量阴影），且 `codebuddy` 使用专属图标，不得误用 CodeBuff 图标。
- R13：客户端图标注册表与当前 Tokscale 权威客户端 ID 对齐；同一产品的兼容 ID 可复用品牌资源，不同产品必须使用独立资源。

## Acceptance Criteria

- [x] AC1：用户可在设置窗口进入“展示配置”页签。
- [x] AC2：开启“隐藏开销为 0 的模型”后，客户端下开销恰好为 0 的模型立即消失；关闭后立即恢复。
- [x] AC3：用户可多选要隐藏的客户端；开启总开关后展开候选列表并隐藏所选客户端，关闭后收起列表、恢复客户端展示且选择仍保留。
- [x] AC4：候选列表覆盖本地全部四个统计周期的客户端并集，并继续显示已选但当前无数据的客户端。
- [x] AC5：两类过滤可同时生效，且不改变未过滤条目的既有排序。
- [x] AC6：保存后的配置在应用重启后保持；缺失新键的旧配置保持完整展示。
- [x] AC7：过滤不会改动 Tokens、成本、排名、活跃天数、状态栏摘要或缓存原始数据。
- [x] AC8：当原始数据有客户端、但全部客户端都被配置隐藏时，面板显示“由展示配置过滤为空”的空状态，不误报为服务端没有明细。
- [x] AC9：偏好存储、候选项并集、组合过滤和关键设置交互具备自动化测试覆盖。
- [x] AC10：客户端候选项显示为带图标的独立 switch，不依赖 Command/Shift 的高亮多选。
- [x] AC11：Dashboard 与 Settings 图标具有一致的圆角与轻量阴影，`codebuddy` 能解析并加载专属资源。
- [x] AC12：当前 Tokscale 权威客户端 ID 均能解析到品牌资源或明确的兼容别名，不会意外回退到通用终端图标。

## Out of Scope

- 修改 Tokscale 数据采集、提交或成本计算逻辑。
- 删除或改写缓存中的客户端、模型数据。
- 按统计周期分别维护不同的隐藏规则。
- 维护一份内置固定客户端清单。
- 因模型过滤结果为空而自动隐藏其所属客户端。

## Key Decisions

- “隐藏指定客户端”使用独立总开关，允许用户临时停用过滤而不清空多选结果。
- 候选客户端使用四个本地统计周期的并集，而不是只使用当前周期或应用内置清单。
- 零开销模型判断采用业务含义明确的精确零值；客户端自身开销为 0 不会因此被隐藏。
- 客户端多选使用每项独立的原生 switch；总开关关闭时收起候选列表并保留选择，重新开启后恢复列表与原选择。
- CodeBuddy 与 CodeBuff 是不同客户端，必须维护独立图标资源与映射。
- TokChan 以 Tokscale 的 `SUPPORTED_CLIENT_TYPES` 为服务端客户端 ID 权威集合，图标注册表需覆盖该集合。
