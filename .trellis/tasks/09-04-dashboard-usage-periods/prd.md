# 浮层用量布局与时间粒度

## Goal

让菜单栏浮层按 Tokscale 官方范围查看用量，核心信息固定、客户端明细独立滚动，客户端图标离线可用。

## Background

- 用户最初要求日/周/月，随后明确“他们接口给的什么我们就是什么”。已核实接口只支持 all/week/month，后续用户要求日数据，已确认逐日 contribution 可直接展示。
- DashboardView.swift 当前整体滚动并展示自动提交，模型无显示上限；TokscaleModels.swift 聚合所有返回贡献为单份显示数据。
- SettingsView.swift 已有自动提交 Tab，可承接运行状态与立即运行。
- 上游合同及线上验证记录见 research/tokscale-period-contract.md；参考图为横向分段条加类别、数值和百分比图例。

## Requirements

- R1：Tab 为全部、日、周、月，初次默认全部，后续恢复上次选择；日取接口 dateRange.end 的逐日记录，日排名为 —；周为接口近 7 天，月为近 30 天。日期边界直接使用返回 dateRange；统计指标（Tokens、成本、排名、活跃天数）、五类构成、客户端及模型全部采用对应响应。
- R2：布局依次为个人信息与数据状态 → 时间粒度 Tab → 统计指标卡 → 用量比例条 → 客户端用量。只有客户端列表滚动，其余内容和底部设置入口固定。
- R3：每客户端默认展示 Tokens 最高的 5 个模型；更多模型通过“展开全部/收起”查看。折叠不影响客户端合计。切换范围后恢复前 5 个。
- R4：复制官方素材目录全部 client-* 图标到项目并打包，已知客户端使用品牌图标，未知客户端回退为通用图标。
- R5：自动提交状态详情与立即运行迁到设置的自动提交 Tab，与现有配置共存；保留加载、错误、运行反馈和保存行为。
- R6：比例条和图例展示 Input、Output、Cache Read、Cache Write、Reasoning 的值与百分比。五类图例始终可见，零值不产生条段；无数据有清晰空状态。
- R7：产品文案中的令牌数统一改为 Tokens。
- R8：范围切换保留账号信息，数据加载或失败时不把旧范围冒充新范围；同范围有效缓存直接展示，不再自动刷新；所有范围和选择持久化到本地 JSON。

## Acceptance Criteria

- AC1（R1/R8）：请求使用 all/week/month，统计、排名、构成和客户端响应范围一致，快速切换不被过期响应覆盖，界面显示接口日期范围。
- AC2（R2）：滚动长客户端列表时其余区域位置固定，380×680 浮层内无整体滚动或溢出，设置入口可用。
- AC3（R3）：超过 5 模型的客户端默认展示最高 5 个，可展开收起，合计包含全部模型。
- AC4（R4）：官方目录全部客户端图标有本地副本，已知客户端断网仍显示图标。
- AC5（R5）：浮层不再显示自动提交块，设置页保留状态详情、最近运行、错误和立即运行功能，操作结果可见。
- AC6（R6）：五类数值采用 stats 返回值，条段比例与图例一致，零用量不除零；窄窗口图例可换行且深浅色可读。
- AC7（R7）：用户可见文案不出现令牌数。
- AC8：相关聚合、请求参数、竞态和缓存测试及 fixture UI 检查通过，提供新的本地 Release app。

## Out of Scope

- 不自行提供自定义日期、本周或自然月统计，不修改服务端日期口径。
- 不变更自动提交调度、账号体系、登录凭据或新增第三方依赖。

## Key Decisions and Compatibility

- API 是时间范围和指标的唯一来源，保留上游 all 的活跃天数语义。
- 客户端百分比分母为对应响应 totalTokens，构成条分母为五类合计，以保证条段总宽度与图例一致，不改写显示的 API 总数。
- 仅缓存映射后的显示快照，不保存原始贡献历史。上一版本单范围快照迁移为一条缓存；完全没有范围的旧格式才丢弃。
- 用户已确认最终方案并授权开工；默认全部，模型支持展开和收起。

## 用户反馈修订（已实施）

- 有本地缓存时不自动请求；全部/日/周/月及上次所选范围均写入 JSON。
- 移除后台更新文案和额外加载图标，数据加载与手动 submit 共用顶部按钮的 loading。
- 关闭浮层不清缓存；手动提交刷新当前范围且保留其他范围。
- day 请求实测回退 all；改为读取官方周响应的末日 contribution，并使用其中的 totals、tokenBreakdown、clients。没有日排名，不借用周排名。
